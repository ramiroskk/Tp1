1 A: Las reglas de java scrip serian


1-tiene sentencias condicionales como if, else, switch y bucles de repetición como for, while o while que garantizan un unico punto de entrada y salida en los bloques de  ejecucion

2- tiene un formato de ejecucion separado por instrucciones como punto y coma(;)  y bloques delimitados con llaves ( { } )

3- tiene reglas para reservar espacios de memoria usando las lineas Let y const las cuales respetan ambitos de bloque

4- tiene procedimientos explicitos mediante la palabra clave function que reciben parametros de valor y referencia y que devuelven un resultado implicito o explicito con return

5- tiene reglas que permiten declarar variables sin especificar el tipo de dato cexplicitamente
